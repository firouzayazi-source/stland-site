# سایت استوک لند — `stland.ir`

کدِ سفارشیِ سایت وردپرسی/ووکامرسی استوک لند. هر چه اینجا روی `main` برود،
سایت خودش از گیت‌هاب برمی‌دارد — SSH و FTP لازم نیست.

| مسیر | چیست |
| --- | --- |
| `wp-content/plugins/stland-home/` | افزونه‌ی صفحه‌ی اصلی (شورت‌کد `[stl_home]`) |
| `wp-content/plugins/stland-updater/` | به‌روزرسان: افزونه‌های بالا را از گیت‌هاب به‌روز می‌کند |
| `wp-content/mu-plugins/stland-site.php` | فقط برای راهِ FTP: نشانیِ وارسیِ انتشار |
| `contract/card-meta.json` | کلیدهای متایی که حسابداری روی هر گوشی می‌نویسد و افزونه می‌خواند |
| `scripts/check.sh` | همه‌ی بررسی‌ها (همان که CI اجرا می‌کند) |
| `scripts/zip.sh` | ساخت zip هر افزونه و `manifest.json` در `dist/` |
| `scripts/verify-bump.php` | اگر افزونه‌ای عوض شده ولی نسخه‌اش بالا نرفته، قرمز می‌کند |

## سینک با حسابداری

داده‌ی تجاری (قیمت، موجودی، دسته، SKU، باتری و ریجستری) را **حسابداری**
(`sthesabland`) با REST ووکامرس به سایت می‌فرستد و سفارش‌ها را از همان‌جا
می‌خواند. این مخزن فقط **نمایش** را می‌سازد. تنظیم اتصال در حسابداری:
«تنظیمات ← سایت».

## چطور تغییر به سایت می‌رسد

1. پوش روی `main` ← ورک‌فلوی `deploy` برای هر افزونه zip می‌سازد و با
   `manifest.json` در Release به نام **latest** می‌گذارد.
2. افزونه‌ی «StockLand Updater» روی سایت آن manifest را می‌خواند و
   نسخه‌ی تازه‌تر را در «افزونه‌ها» و «به‌روزرسانی‌ها» مثل هر آپدیت دیگری
   نشان می‌دهد؛ اگر «به‌روزرسانی خودکار» روشن باشد خودش نصب می‌کند.

⛔ وردپرس فقط نسخه‌ی **بالاتر** را نصب می‌کند. هر تغییری در یک افزونه
یعنی بالا بردن `Version` آن (و برای `stland-home`، `STLH_VER` هم). ورک‌فلو
اگر فراموش شود قرمز می‌شود.

## راه‌اندازی (یک بار)

1. مخزن باید **عمومی** باشد تا سایت بی‌کلید بخواندش: Settings ← General
   ← Danger Zone ← Change visibility ← Public.
2. از Releases ← latest فایل `stland-updater.zip` را دانلود کنید.
3. پیشخوان وردپرس ← افزونه‌ها ← افزودن ← بارگذاری افزونه ← همان zip ←
   نصب ← فعال‌سازی.
4. تنظیمات ← «به‌روزرسانی استوک لند» ← «آزمایش اتصال به گیت‌هاب». هر دو
   ردیف باید ✅ باشند.

## راهِ FTP (خاموش)

هاست نت‌افراز ورودِ FTP از آی‌پیِ خارج را با `531 You are not authorized`
رد کرد. کدش مانده: اگر روزی هاست باز کرد، متغیر مخزن `FTP_DEPLOY` را
`on` کنید (Settings ← Secrets and variables ← Actions ← Variables).
Secretهای `FTP_SERVER`، `FTP_USERNAME`، `FTP_PASSWORD` و
`FTP_REMOTE_DIR` (= `/` برای حساب `deploy@stland.ir`) از قبل تعریف
شده‌اند. نشانیِ وارسی: `https://stland.ir/wp-json/stland/v1/health`.
