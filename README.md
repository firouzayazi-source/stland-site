# سایت استوک لند — `stland.ir`

کدِ سفارشیِ سایت وردپرسی/ووکامرسی استوک لند. هر چه اینجا روی `main` برود،
خودکار با **FTP** روی هاست اشتراکی می‌نشیند — SSH لازم نیست.

| مسیر | چیست |
| --- | --- |
| `wp-content/plugins/stland-home/` | افزونه‌ی صفحه‌ی اصلی (شورت‌کد `[stl_home]`) |
| `wp-content/mu-plugins/stland-site.php` | نشانیِ وارسیِ انتشار و پاک کردن کش بعد از هر انتشار |
| `contract/card-meta.json` | کلیدهای متایی که حسابداری روی هر گوشی می‌نویسد و افزونه می‌خواند |
| `scripts/check.sh` | همه‌ی بررسی‌ها (همان که CI اجرا می‌کند) |
| `scripts/zip.sh` | ساخت `dist/stland-home.zip` برای آپلود دستی |

## سینک با حسابداری

داده‌ی تجاری (قیمت، موجودی، دسته، SKU، باتری و ریجستری) را **حسابداری**
(`sthesabland`) با REST ووکامرس به سایت می‌فرستد و سفارش‌ها را از همان‌جا
می‌خواند. این مخزن فقط **نمایش** را می‌سازد و هیچ‌وقت آن داده را خودش
نمی‌نویسد. تنظیم اتصال در حسابداری: «تنظیمات ← سایت».

## راه‌اندازی انتشار خودکار (یک بار)

### ۱. اطلاعات FTP از کنترل‌پنل هاست

در cPanel یا DirectAdmin بخش «FTP Accounts» یک حساب FTP بسازید (یا همان
حساب اصلی) و این‌ها را بردارید: نشانی سرور، نام کاربری، رمز. مسیرِ
وردپرس را هم ببینید — جایی که `wp-config.php` هست. در cPanel معمولاً
`/public_html/` و در DirectAdmin معمولاً `/domains/stland.ir/public_html/`.

### ۲. تعریف Secretها در گیت‌هاب

مخزن ← Settings ← Secrets and variables ← Actions ← New repository secret:

| نام | مقدار | اجباری |
| --- | --- | --- |
| `FTP_SERVER` | مثلاً `ftp.stland.ir` | بله |
| `FTP_USERNAME` | نام کاربری FTP | بله |
| `FTP_PASSWORD` | رمز FTP | بله |
| `FTP_REMOTE_DIR` | مسیر وردپرس با `/` در انتها؛ پیش‌فرض `/public_html/` | اگر فرق دارد |
| `FTP_PROTOCOL` | `ftps` (پیش‌فرض) — اگر هاست FTPS ندارد: `ftp` | اگر خطا داد |
| `FTP_PORT` | پیش‌فرض `21` | به‌ندرت |

### ۳. آزمایش

Actions ← deploy ← Run workflow، یک بار با تیکِ `dry_run` (فقط فهرست
فایل‌ها) و بعد بدون آن. در پایان، این نشانی باید همان کامیت را نشان دهد:

```
https://stland.ir/wp-json/stland/v1/health
```

## اگر FTP از گیت‌هاب وصل نشد

بعضی هاست‌های ایرانی اتصال از خارج را می‌بندند. هر پوش روی `main` فایل
`stland-home.zip` را در Release به نام **latest** می‌گذارد. در پیشخوان
وردپرس: افزونه‌ها ← افزودن ← بارگذاری افزونه ← همان zip ←
«جایگزینی نسخه‌ی فعلی با نسخه‌ی بارگذاری‌شده». تنظیمات افزونه دست نمی‌خورد.
