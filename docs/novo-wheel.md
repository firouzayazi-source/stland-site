# گردونه‌ی شانس — قرارداد با Novo

گردونه‌ی ربات (`stockland-bot`: `core/wheel.py` + مینی‌اپ) در سایت هم هست: برگه‌ی `/wheel/` («گردونه شانس»)، «حساب من ← گردونه
شانس»، کارتِ صفحه‌ی اصلی و منوی «ابزارها و جوایز» (`includes/wheel.php`، `assets/wheel/`).

**صاحب فروشگاه (۶ آذر ۱۴۰۵):** فقط مشتریِ واردشده می‌چرخاند؛ «اعتبارِ کیف‌پول» ربات این‌جا **کدِ تخفیفِ مبلغی** است؛ تعریفِ جوایز و
پیگیریِ برنده‌ها در Novo. تا اولین ارسال، شش جایزه‌ی پیش‌فرضِ ربات (۵ و ۱۰ هزار تومان تخفیف، ۱۰٪ و ۲۰٪ تخفیف با سقفِ ۱۰۰ هزار تومان،
چرخشِ اضافه، پوچ) فعال است.

همه‌ی مسیرها زیرِ `https://stland.ir/wp-json/stland/v1/wheel` و با رمزِ برنامه‌ی مدیر (مثلِ سفارش‌ها).

## ۱. پیکربندی — `GET|POST /config`

هر کلید اختیاری است؛ کلیدی که بیاید جای همان بخش را کامل می‌گیرد، `null` آن بخش را به پیش‌فرض برمی‌گرداند. `GET` پیکربندیِ مؤثر را
می‌دهد (`{ok, pushed, config}`).

```json
{
  "version": "2026-11-27-1",
  "settings": {"enabled": true, "title": "🎡 چرخ‌گردون شانس", "description": "هر روز یک شانس رایگان برای بردن جایزه!",
               "daily_spin_limit": 1, "reset_hour": 0, "animation_duration_ms": 5200,
               "sound_enabled": true, "haptic_enabled": true, "show_odds": false},
  "campaign": {"id": 1, "title": "کمپین یلدا", "ends_at": null},
  "prizes": [
    {"id": "p1", "title": "۵۰ هزار تومان تخفیف", "wheel_label": "۵۰ هزار", "icon": "💵", "color": "#22C55E",
     "prize_type": "discount_fixed", "value": 50000, "min_purchase_amount": 2000000, "validity_hours": 72,
     "weight": 1, "total_limit": 0, "daily_limit": 0, "active": true, "sort_order": 0, "description": "",
     "product_ids": [], "category_ids": []}
  ]
}
```

* `prize_type`: `discount_fixed` (مبلغ به تومان)، `discount_percent` (درصد، با `max_discount_value` تومان = سقفِ تخفیف)، `extra_spin`
  (`value` = تعداد چرخشِ اضافه)، `no_win`، `physical_gift` (هدیه؛ برنده آدرس ثبت می‌کند). `wallet_credit` ربات خودکار `discount_fixed` می‌شود.
* کدِ تخفیف یک کوپنِ واقعیِ فروشگاه است (`WH-…`): فقط ایمیلِ همان حساب، یک بار، انقضا با `validity_hours`، حداقلِ خرید با
  `min_purchase_amount` (تومان)، محدود به `product_ids`/`category_ids` (شناسه‌های همین سایت) اگر پر باشد، و «فقط همین کوپن».
* `weight` احتمالِ نسبی است؛ `total_limit`/`daily_limit` (۰ = بی سقف) سهمیه‌ی کل/روزانه‌ی هر جایزه. وقتی همه‌ی جوایزِ محدود تمام شد، «بدون برد».
* `daily_spin_limit` = چرخشِ رایگانِ روزانه‌ی هر حساب (۰ = نامحدود)؛ روز به وقتِ تهران از ساعتِ `reset_hour`.
* `id` جایزه را ثابت نگه دارید؛ آمار و سهمیه به آن بسته است.

## ۲. برنده‌ها و آمار

| مسیر | چه می‌دهد |
|---|---|
| `GET /spins?days=30&type=` | چرخش‌ها: کاربر (نام، ایمیل)، جایزه، کدِ تخفیف، انقضا، وضعیت، وضعِ هدیه |
| `GET /gifts?status=none\|pending\|sent` | برنده‌های هدیه‌ی فیزیکی با نام، تلفن و آدرسِ ثبت‌شده |
| `POST /gifts/<id>` | `{status: "pending"\|"sent", note}` — «ارسال شد» یک ایمیل به برنده می‌فرستد |
| `GET /stats?days=30` | هر جایزه: تعداد، کاربرِ یکتا، و برای کدِ تخفیف تعدادِ استفاده‌شده |

ثبتِ آدرسِ هدیه و بردِ هدیه هر کدام یک ایمیل به مدیرِ سایت هم می‌فرستد.

## ۳. قاعده‌ها

* انتخابِ جایزه ۱۰۰٪ سمتِ سرور است (عینِ `core/wheel.py`)؛ رزروِ شناسه‌ی درخواست + شمارنده‌ی روزانه و سهمیه با UPDATE شرطی — دو کلیک
  هرگز دو جایزه نمی‌دهد.
* «نمایشِ خودکارِ گردونه» ربات در سایت نیست (برای مشتریِ سایت مزاحم است).
